# Nasi Goreng Rush

A fast-paced cooking game built for the make.fun bounty - Make the best game.
Cook and serve Nasi Goreng as fast as you can before customers get angry!

## How to play

Open `index.html` or run the dev server below. Serve orders, keep your combo up, and don't burn the rice!
